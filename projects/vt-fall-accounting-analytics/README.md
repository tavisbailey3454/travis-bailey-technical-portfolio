# VT Fall Accounting and Inventory Analytics

Excel workbook collection from ACIS coursework that supports the business analytics side of the portfolio.

## Included Workbooks

- `inventory-transactions-sku-analysis.xlsx` - 30,000+ inventory transaction records, SKU alert logic, return-ratio analysis, and SKU list structure.
- `pro-forma-loan-lease-analysis.xlsx` - loan, lease, income statement, and future net income modeling.
- `personal-budget-analysis.xlsx` - formula-driven personal budget workbook with percent-to-total analysis.

## What It Demonstrates

- Excel analytics and formula work
- Inventory transaction analysis
- SKU and return-ratio reporting
- Pro forma financial modeling
- Loan and lease analysis
- Budget and percent-to-total modeling
