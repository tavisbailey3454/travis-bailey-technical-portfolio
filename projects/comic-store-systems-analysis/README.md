# Comic Store Systems Analysis

Systems analysis project for an online comic store workflow.

## What It Demonstrates

- Requirements analysis
- Use-case modeling
- Swimlane process mapping
- Class diagramming
- CRUDE matrix documentation
- Connecting business processes to system responsibilities

## Resume-Ready Summary

Modeled an online comic store system using use cases, swimlane diagrams, a class diagram, and a CRUDE matrix to document checkout, inventory, shopping cart, and comic-management requirements.
