# R Data Story and Visual Analytics

R project that turns public datasets into polished visual summaries and exportable analysis outputs.

## What It Demonstrates

- Excel and CSV ingestion
- Data cleaning and transformation with dplyr and tidyr
- Visual storytelling with ggplot2
- Reusable charting and export functions
- Public-data analysis and written interpretation support

## Resume-Ready Summary

Created an R analytics workflow that cleans public datasets, builds comparative summaries, and exports publication-style charts for business and social-data storytelling.
