# K-means Text Clustering

R text analytics project that clusters financial news sentences using TF-IDF features.

## What It Demonstrates

- Text cleaning and tokenization
- Stop-word filtering
- TF-IDF matrix construction
- K-means clustering
- PCA visualization
- Cluster interpretation through top-word and sentiment summaries

## Resume-Ready Summary

Built an R workflow to transform raw text into TF-IDF features, run K-means clustering, and produce visual summaries that explain cluster size, dominant sentiment, and top text features.
