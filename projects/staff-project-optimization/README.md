# Staff Project Optimization App

Python desktop application that assigns staff to projects while minimizing labor and idle-hour costs.

## What It Demonstrates

- API data loading and normalization
- Linear programming with PuLP
- Binary decision variables and workload constraints
- PyQt6 user interface development
- Matplotlib charts for staffing, project, cost, and workload summaries

## Resume-Ready Summary

Built a Python/PyQt optimization app using API data and PuLP to assign staff to projects under weekly workload and role constraints, producing cost, profit, and billable-hour dashboards for decision support.
