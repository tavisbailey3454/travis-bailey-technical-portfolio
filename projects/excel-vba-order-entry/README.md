# Excel VBA Order Entry System

Macro-enabled Excel workbook built around a Hokie Shirt order workflow.

## What It Demonstrates

- Excel workbook application design
- Multi-sheet data structure
- Order-entry form logic
- Customer, product, and order-history tables
- Formula-backed lookups and workbook automation concepts

## Resume-Ready Summary

Built a macro-enabled Excel order-entry workbook with separate order form, product list, customer list, and order-history sheets to support structured data entry and transaction tracking.
